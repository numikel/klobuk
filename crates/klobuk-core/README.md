# klobuk-core

Klobuk core: domain types, ports (IssueStore, Vcs, AgentRuntime), scheduler and configuration, no IO.

Part of [Klobuk](https://github.com/numikel/klobuk), the autonomous software factory. See the [project README](https://github.com/numikel/klobuk#readme) for what it does and how to install it.
